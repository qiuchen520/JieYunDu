## 极云渡 0.1.0

首个公开版本。Android 网盘分享解析与高速下载工具，液态玻璃界面，平板优先。

### 支持网盘

- **夸克网盘**：分享解析 / 个人网盘浏览与管理 / 下载
- **UC 网盘**：分享解析 / 个人网盘浏览与管理 / 下载
- 百度网盘、迅雷云盘：**开发中**，本版不可用

### 主要功能

- **分享解析**：粘贴分享链接（含提取码）→ 展开目录 → 勾选批量下载；
- **高速下载**：HTTP Range 分片并发（32–512 档，默认 64）、断点续传；
- **下载控制**：暂停 / 继续 / 重新下载，下载中实时速度 · 均速 · 已下载/总量 · 剩余时间；
- **下载增强**：同时下载任务数、全局限速、失败自动重试；
- **后台保活**：前台服务 + 可选唤醒锁（锁屏继续下载），通知栏进度可关闭；
- **网盘管理**：App 内浏览自己的网盘（容量 / 目录），下载到本地、删除文件（移入网盘回收站）；
- **本地成品**：默认发布到公共 `Download/极云渡/`，任意文件管理器可见；支持自定义目录；
- **诊断支持**：崩溃日志与运行日志导出（便于反馈问题）。

### 安装

下载下方 `app-release.apk` 安装即可。升级时同签名可直接覆盖安装，不会丢登录态。

### 系统要求

- Android **8.0（API 26）** 及以上；
- 需要网络权限；通知权限（Android 13+）用于展示下载进度，可拒绝；
- 默认下载到公共目录**无需存储权限**；仅当你主动选择「自定义下载目录」时才需要「所有文件访问」权限。

### 已知问题

1. **UC 个人网盘文件暂不支持「下载到本地」**：UC 该接口缺少个人文件的抓包依据，为避免编造参数，
   App 会明确提示；请改用分享链接下载。后续补齐证据即可支持，界面无需改动。
2. 分享直链有时效：长时间暂停后再「继续」可能因直链过期失败，此时请用「重新下载」。
3. 百度、迅雷网盘开发中，入口存在但不可用。
