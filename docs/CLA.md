# 极云渡 · 贡献者许可协议（Contributor License Agreement, CLA）

> **性质**：本文件是**贡献门槛**，与项目自身协议（AGPL-3.0，见仓库根 `LICENSE`）是**两回事**。
> 提交贡献（PR / 补丁 / 代码片段）前，贡献者须先签署本协议。
>
> **模板来源**：本协议正文基于 **Apache Software Foundation 的 Individual Contributor
> License Agreement（ICLA）V2.2** 模板改编，仅将受益主体由「Apache Software Foundation」
> 替换为本项目**版权所有者（the Owner，下称「本项目所有者」）**，并把签署方式由邮件改为
> **在 PR 评论中回复指定语句**（见 §签署方式）。
>
> **授权方式**：**版权许可（非转让）**。贡献者**保留其贡献的版权**，但授予本项目所有者
> **永久的、免费的、可再许可（sublicense）的**权利，以便所有者可对项目进行闭源收费 /
> 双版本（开源 + 闭源）分发，而无需逐一向贡献者签字确认。此与 Apache ICLA 的语义一致。
>
> **法律文本以英文为准**，下方中文为参考译文。

---

## 签署方式

在 Pull Request 的评论区回复**下列语句**（逐字，区分大小写与标点）：

```
I have read the CLA Document and I hereby sign the CLA
```

回复后由仓库的 CLA Assistant 自动校验并记录签署（见 `.github/workflows/cla.yml`）。
如签署状态需重新校验，可在 PR 评论中回复 `recheck`。
