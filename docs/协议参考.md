```

### 参数名 / 常量
| 名称 | 说明 |
|---|---|
| 根目录 `pdir_fid` | `0` |
| 直链下载 `Referer` | `https://pan.quark.cn/`（防盗链，必须带） |
| Cookie 有效性判定 | 必须**同时**包含 `__pus=` 和 `__puus=` |
| `__puus` 有效期 | 约 3 小时，建议**每 90 分钟刷新一次**（用 config 等轻接口重新下发） |
| 临时转存目录名 | 自定义（本项目用 `.极云渡临时`，避免撞名） |

### 两套 UA（不能混用）
```
网页 / 登录态：
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0.0.0 Safari/537.36 QuarkPC/6.0.8.649

API / 客户端（取链与下载用这个）：
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) quark-cloud-drive/2.5.20 Chrome/100.0.4896.160 Electron/18.3.5.12-a038f7b798 Safari/537.36 Channel/pckk_other_ch
```

### 真实链路（7 步；与旧版差异重点）
```
1) GET https://pan.quark.cn  → Set-Cookie 取 __pus + __puus
2) POST sharepage/token      → stoken
3) GET  sharepage/detail     → 文件列表 + fid + share_fid_token
4) POST sharepage/save       → 转存到自己网盘，返回 save_as.save_as_top_fids[0]
5) GET  task?task_id=xxx     → 轮询直到转存完成
6) POST file/download        → 传【自己网盘里的 fid】，拿 download_url
7) 下载直链必须带 Referer: https://pan.quark.cn/
```
> 第 4、5 步不可省略：`file/download` 只认自己网盘的文件，直接传分享 fid 拿不到直链。

```

## 6. 接口字段名（请求体 / 响应体）

> 用 `org.json` 手拼 JSON，字段名明文、可逐一核对。

### 6.1 夸克 / UC 共用结构

**① 取 token** `POST .../sharepage/token`
```jsonc
// 请求
{ "pwd_id": "<shareId>", "passcode": "<提取码 或 空串>",
  // 夸克: "support_visit_limit_private_share": true
  // UC  : "share_for_transfer": true        ← 两家字段不同，别抄混
}
// 响应
{ "status": 200, "code": 0,
  "data": { "stoken": "...", "title": "...", "first_fid": "..." } }
```

**② 列分享文件**
- 夸克 `GET .../sharepage/detail?pr=ucpro&fr=pc`（POST body）
- UC `POST .../sharepage/v2/detail`
```jsonc
// 请求
{ "pwd_id": "<shareId>", "passcode": "...", "pdir_fid": "<目录fid>",
  "force": 0, "page": 1, "size": 50,
  "fetch_banner": 1, "fetch_share": 1, "fetch_total": 1,
  "sort": "file_type:asc,file_name:asc",
  "banner_platform": "other", "web_platform": "windows",
  "fetch_error_background": 1 }
// 响应：优先 data.detail_info.list[]；兼容旧版直接 data.list
//   （实现写法：detail_info?.list ?: list）
//   每项: fid / file_name / size / dir / pdir_fid / share_fid_token / updated_at
```

**③ 转存** `POST .../sharepage/save`
```jsonc
// 请求
{ "pwd_id": "<shareId>", "stoken": "<stoken>",
  "pdir_fid": "<目标目录，根为 0>", "to_pdir_fid": "<同上>",
  "fid_list": ["<fid>"], "fid_token_list": ["<share_fid_token>"],
  "scene": "link" }
// 响应：data.task_id
// 注：转存目标先留【根目录】——pdir_fid / to_pdir_fid 传 0 即可；
//   临时目录 + 自动清理见 §9（阶段 13）。
```

**④ 任务轮询** `GET .../task?pr=ucpro&fr=pc&task_id=xxx`
```jsonc
// 完成判定（三个任一）：
//   data.finished_at > 0
//   data.status == 2
//   data.task_status == 2
// 转存后的新 fid：data.save_as.save_as_top_fids[0]
```

**⑤ 取直链** `POST .../file/download`
（夸克带 `?pr=ucpro&fr=pc&sys=win32&ve=3.23.2`；UC 带 `?entry=ft&fr=pc&pr=UCBrowser`）
```jsonc
// 请求 —— 注意是 "fids"，不是 "fid_list"
{ "fids": ["<自己网盘里的 fid>"] }
// 响应
{ "status": 200, "code": 0,
  "data": [ { "fid": "...", "file_name": "...", "download_url": "..." } ] }
// 失败时看 json.message / json.code
```

**⑥ 创建目录（个人网盘）** `POST .../file?pr=ucpro&fr=pc`（UC：`?pr=UCBrowser&fr=pc`）
```jsonc
// 请求
{ "pdir_fid": "<父目录 fid，根为 0>", "file_name": "<新目录名>",
  "dir_path": "", "dir_init_lock": false }
// 响应：data.fid（新目录 fid）
```

### 6.2 百度
```
gettemplatevariable  →  result.bdstoken / result.username
share/verify         →  randsk（URL 编码形式，直接当 sekey）
xpan/share?method=list
     完整参数：&shorturl=<surl>&page=1&num=100&root=<1|0>&dir=<urlencode 路径>[&sekey=<randsk>]
     响应：title / share_id / uk / list[]
        每项：fs_id / server_filename / size / isdir("1"或"0") / path / server_mtime
        目录项要用 path 当 id，文件项用 fs_id
share/transfer
     ?shareid=&from=<uk>&channel=chunlei&sekey=&ondup=newcopy&web=1&app_id=250528&bdstoken=&clienttype=0
     body: fsidlist=["<fsId>"]&path=<urlencode 目标目录>
     响应：extra.list[0].to_fs_id（新 fs_id）/ extra.list[0].to（新完整路径）
locatedownload
     POST d.pcs.baidu.com/rest/2.0/pcs/file?method=locatedownload&path=<转存后完整路径>&…
     响应：urls[]  每项 { url, encrypt(0=明文/1=加密), rank }
          选链策略：encrypt==0 优先 → https 优先 → 兜底第一个
     另有 info[0].dlink（需 errno==0）
建目录（个人网盘，新建文件夹）
     POST https://pan.baidu.com/api/create?a=commit&channel=chunlei&web=1
          &app_id=250528&clienttype=0&bdstoken=<bdstoken>
     Header：UA `netdisk;12.24.6;…` / Referer https://yun.baidu.com/disk/main
             Content-Type application/x-www-form-urlencoded; charset=UTF-8
     body(form)：path=<urlencode 完整路径>&isdir=1&size&block_list=%5B%5D&method=post&dataType=json
     成功判定：errno == 0
     ⚠️ 纯 Cookie 认证下 filemanager?opera=mkdir 恒 errno=2，必须走 /api/create?a=commit
     ⚠️ bdstoken 由 gettemplatevariable 取（可缓存），建目录必须带
```
**两个必踩的坑**
- 子目录（`root=0`）**必须带 `BDCLND` cookie**（值 = verify 的 randsk），否则 `errno=2`；顶层（`root=1`）不需要
- share/verify 响应本身就会 `Set-Cookie: BDCLND=<randsk>`，可自动或手动补齐

## 7. 两个关键机制（重要）

### 7.1 游客令牌 `__pugs` —— 不下发就跑不通
夸克/UC 在**未登录**访问分享链接时，响应 `Set-Cookie` 会下发 **`__pugs`** 令牌（约 3 小时有效）。

- 夸克游客直链域名为 `dl-guest-*`：**不回带 `__pugs` → CDN 直接 412**
- UC：**缺它 OSS 直链直接 403**（`RequestDeniedByCallback`）
- 登录态路径不受影响；进程内复用即可

### 7.2 Cookie 必须持续合并回写
`__puus` / `__pus` 会随任意响应刷新。正确做法：
1. 每次响应取 `Set-Cookie`，把最新的 `__puus`/`__pus` **合并回原 Cookie 串**
2. 定期“刷新”：**临时剥掉 `__puus` 再请求**，服务端会重新下发一个
3. 回写落库（`cookieSink` 式回调）

### 7.3 夸克 CDN：不要改写 host
官方下发的 `download_url` 里的 host（如 `dl-*.quark.cn`）与签名绑定。
自行改写 host 或预先 GET 探测会 ①消耗直链额度 ②可能 412。**原样使用即可**。
