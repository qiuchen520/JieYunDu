# 极云渡 (JieYunDu)

网盘分享链接解析 + 高速下载工具，液态玻璃 UI，平板优先。

## 当前版本

**0.1.0**（`versionCode = 1`）。当前支持 **夸克网盘** 与 **UC 网盘**。

## 支持网盘

| 网盘 | 解析分享 | 浏览/管理个人网盘 | 下载 | 备注 |
|---|---|---|---|---|
| 夸克 | ✅ | ✅ | ✅ | 分享转存取链 / 个人文件直取直链 |
| UC | ✅ | ✅ | ✅ | 分享直连取链（免转存） |
| 百度 | ✅ | — | — | 分享解析与目录浏览已可用（含提取码两阶段判定）；个人网盘与下载待后续 |
| 迅雷 | 🚧 占位 | — | — | 骨架（协议参数需实测证据后方可实现） |

## 主要功能

- **分享解析**：粘贴分享链接（支持带提取码），展开目录、勾选文件批量下载；
- **高速下载**：HTTP Range 分片并发（可调 32–512，默认 64），断点续传、暂停/继续/重新下载；
- **下载增强**：同时任务数上限、全局限速、失败自动重试；
- **后台保活**：前台服务 + 可选唤醒锁，锁屏继续下载，通知栏进度可关；
- **网盘管理**：在 App 内浏览自己的网盘（容量 / 目录），可下载到本地、删除文件（移入网盘回收站）；
- **本地成品**：默认发布到公共 `Download/极云渡/` 目录，任意文件管理器可见；也可指定自定义目录；
- **其它**：下载列表实时速度/均速/剩余时间、崩溃与运行日志导出。

## 代码结构（分层）

代码按「UI → domain ← data」单向依赖组织；`domain` 不反向依赖 `data`——它只声明端口接口，
由 `data` 实现、`di` 绑定。

| 层 | 目录 | 职责 |
|---|---|---|
| 界面 | `ui/` | Compose 页面与组件；`ui/glass`（玻璃材质）、`ui/icons`（自绘图标）、`ui/theme`（颜色 / 尺寸 / 字体）、`ui/navigation`（Q 弹导航） |
| 领域 | `domain/` | 纯逻辑：`parser`（四家网盘协议：接口定义 + wire 模型 + 解析器）、`transfer`（转存 / 取链 / 临时目录 / 删除守卫）、`downloader`（分片下载引擎：门面 / 分片 / 运行态 / 进度测速 / 限速器 / 端口契约）、`login`、`model` |
| 数据 | `data/` | Room 持久化、Cookie 仓库与拦截器、设置、落盘与公共目录发布 |
| 服务 | `service/` | 前台下载服务、通知、唤醒锁 |
| 装配 | `di/` | 依赖注入模块（业务类只标注 `@Inject` / `@Singleton`，装配集中在此） |
| 入口 | `ui/MainActivity.kt` | 唯一 Activity |

约定：

- 每个 `.kt` 文件以四行文件头开头：文件 / 职责 / 依赖 / 协议（便于按职责定位）；
- 端口接口定义在 `domain`，实现放在 `data`，绑定写在 `di`；
- 自绘图标统一放 `ui/icons/`；用户可见文案一律走 `res/values/strings.xml`；
- 可复用视觉常量集中在 `ui/theme`（颜色 / 尺寸 / 字体），协议常量集中在各 `*Api` / `*Models`。

完整文件清单（精确到文件）见 [`要求.md`](要求.md) 第六部分。

## 安装

从 **GitHub Releases** 页面下载最新 APK 安装。

- 系统要求：**Android 8.0（API 26）及以上**；
- 覆盖安装：同一签名的版本可直接覆盖升级，不会丢登录态；
- 首次使用需在「网盘」页登录对应网盘（内嵌网页登录，登录态仅保存在本机加密存储）。

## 已知限制

- **UC 个人网盘文件暂不支持「下载到本地」**：UC 的 `file/download` 接口对个人文件缺少抓包依据
  （其请求体强制要求分享态字段），为避免编造接口参数，App 会给出明确提示，请改用分享链接下载；
  后续补齐抓包事实即可打通（UI 无需改动）。
- 百度、迅雷网盘仍在开发中，暂不可用。
- 分享直链有时效：暂停很久后再继续可能因直链过期而失败，此时请使用「重新下载」。

## 构建

本项目通过 GitHub Actions 云端编译，无需本地安装 Android SDK。

- 推送到 `main` 分支：自动构建 **debug** APK（Actions 页面下载产物）；
- 手动触发 `Build APK` 工作流并选择 `build_type = release`：构建 **release** APK。

CI 使用官方 `gradle/actions/setup-gradle`（固定 Gradle 8.2.1），不依赖
`gradle-wrapper.jar`——该二进制文件未随本次交付的文本接口入库。
（Gradle 官方无 8.2.2 发行版；8.2.2 为 AGP 版本号，勿混淆。）

签名：CI 从仓库 Secrets 还原固定 keystore 完成签名；**keystore 与口令不进入仓库**
（`.gitignore` 已忽略 `*.jks` / `*.keystore` / `*.p12` / `*.pem` / 口令文件）。

本地构建（可选）：自备 Gradle 8.2.1 与 JDK 17 后执行

    gradle assembleDebug     # 调试包
    gradle assembleRelease   # 发布包（需自行提供签名密钥）
